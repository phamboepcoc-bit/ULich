Tuần 1
🎉 Sẵn sàng import vào Google Calendar!
Tải file ICS rồi làm theo hướng dẫn bên dưới.
1
Tải file ICS
Nhấn nút đen phía trên để tải toàn bộ lịch học về máy.
2
Tạo lịch mới (Quan trọng)
Vào Trang Tạo Lịch, đặt tên lịch rồi ấn Create calendar.
3
Import vào lịch vừa tạo
Vào Import & Export. Tải file ICS lên, chọn đúng tên lịch vừa tạo ở mục "Add to calendar" rồi ấn Import.
4
Xong! 🎉
Toàn bộ lịch học sẽ xuất hiện trên Google Calendar.
